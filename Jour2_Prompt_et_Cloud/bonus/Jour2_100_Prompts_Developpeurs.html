100 prompts pour développeurs, dans la structure du support

Chaque prompt est écrit dans les six blocs du cours et étiqueté avec la technique du module 3 qu'il applique. Ils sont classés selon les six étapes de la slide « Un prompt pour chaque étape d'un projet ». Les mots entre crochets sont vos variables : remplacez-les, collez, relancez, corrigez.

La structure, rappel du support

RÔLEqui parle, avec quelle expertise, ce qu'il vérifie systématiquement
CONTEXTEle projet, les contraintes techniques, ce qui existe déjà
TÂCHEune seule action, exprimée par un verbe précis
CONTRAINTESce qui est imposé : version, dépendances, style, longueur
FORMATla structure exacte attendue en sortie
EXEMPLEune entrée avec la sortie voulue

Si un prompt ne marche pas, vérifiez d'abord lequel des six blocs manque. Neuf fois sur dix, c'est FORMAT ou CONTEXTE.

La self-consistency (technique 4) est une méthode d'exécution, pas une forme de prompt : n'importe lequel de ces cent prompts, posé trois fois dans trois conversations séparées avec une réponse fermée, l'applique.
