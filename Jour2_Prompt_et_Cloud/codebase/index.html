Dans quel ordre travailler

  1. Parcourez les six techniques. Pour chacune, copiez le modèle et essayez-le une fois.
  2. Faites la self-consistency pour de vrai : trois conversations séparées, pas trois messages à la suite.
  3. Rédigez votre prompt de spécification, puis passez la grille sur 10.
  4. Corrigez votre prompt — pas la réponse — et recomptez.
  5. Construisez la page « Bonnes Nouvelles », puis mettez-la en ligne.
Le chiffre de la journée : entre le modèle le plus cher et le moins cher, il y a un facteur 46 pour un travail identique. Classer un titre est une tâche fermée : le surcoût n'achète rien.
La règle de la journée : un prompt ne s'écrit pas, il se corrige. La première version n'est jamais la bonne, et ce n'est pas un problème — c'est la méthode.
