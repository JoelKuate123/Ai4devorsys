La sélection.

Le document privilégie les projets qui permettent de comprendre les briques d’une stack IA moderne : runtime d’agents, outils, données, contrôle, sécurité et mise en production.

01 Agent Runtime

DeepSeek Harness

Agents · Plugins · TypeScript

Ce que c’est

Un harness d’agents open source développé par DeepSeek, construit autour d’une architecture où « tout est plugin ».

Pourquoi regarder

Intéressant pour étudier une architecture d’agents extensible, les frontières plugin/runtime et la composition de capacités.

Cas d’usage

Construire un environnement d’agents modulaire, remplacer facilement des composants et expérimenter des workflows multi-outils.

Projet en évolution rapide : à évaluer comme base technique avant usage production.
GitHub deepseek-ai/deepseek-harness
02 Architecture

Archify

Diagrammes · Agents · HTML/SVG

Ce que c’est

Un skill d’agent qui transforme un codebase ou une description système en cartes d’architecture interactives et vérifiables.

Pourquoi regarder

Très utile pour documenter un système existant, préparer une revue d’architecture ou expliquer des flux complexes.

Cas d’usage

Architecture, séquences, data-flow, lifecycle, export HTML/SVG et comparaison avant/après.

Pertinent pour les équipes qui veulent rendre l’architecture lisible sans maintenir des diagrammes manuellement.
GitHub tt-a1i/archify
03 Coding Skill

Ponytail

YAGNI · Minimalisme · Code review

Ce que c’est

Un plugin/skill qui pousse les agents de code vers des solutions plus simples : YAGNI, standard library d’abord, moins de dépendances.

Pourquoi regarder

Il attaque un défaut classique du code généré par IA : le sur-engineering et les abstractions inutiles.

Cas d’usage

Réduire la complexité, challenger un plan technique et améliorer les revues de code produites par des agents.

À utiliser comme garde-fou méthodologique, pas comme remplacement d’une vraie revue d’architecture.
GitHub DietrichGebert/ponytail
04 Data Hygiene

Watermarks Remover

Métadonnées · Unicode · Provenance

Ce que c’est

Des scripts et skills pour nettoyer certains marqueurs de provenance IA : caractères invisibles, métadonnées et informations de conteneur.

Pourquoi regarder

Utile pour auditer ce qui reste attaché à un document ou une image avant diffusion, archivage ou traitement.

Cas d’usage

Hygiène documentaire sur des contenus que vous possédez, normalisation Unicode et suppression de métadonnées explicites.

Ne garantit pas la suppression de tous les watermarks perceptuels, audio ou pixel-level.
GitHub guillaumemeyer/watermarks-remover
05 Document AI

Anydoc

Rust · Markdown · Parsing

Ce que c’est

Une bibliothèque Rust qui convertit Word, PowerPoint, Excel, PDF, EPUB, CSV et autres formats en Markdown propre.

Pourquoi regarder

Très pratique pour préparer rapidement des documents destinés à un pipeline RAG ou à un agent.

Cas d’usage

Ingestion documentaire, pré-traitement LLM, conversion locale via CLI, Node.js, Python ou WebAssembly.

Pour les documents scannés complexes, prévoir une couche OCR complémentaire.
GitHub firecrawl/anydoc
06 Developer OS

Omarchy

Arch Linux · Hyprland · Agentic

Ce que c’est

Une distribution Linux opinionated, basée sur Arch, Hyprland et Quickshell, pensée pour un poste de travail développeur moderne.

Pourquoi regarder

Intéressant comme référence d’environnement de développement fortement intégré et orienté productivité/agents.

Cas d’usage

Workstation dev, terminal-first, IA, outils de développement et personnalisation d’un environnement complet.

À considérer comme environnement opinionated : sa valeur dépend fortement des habitudes de l’équipe.
GitHub omacom/omarchy
07 Agentic Business App

Comp AI CRM

CRM · Agents · Automation

Ce que c’est

Un CRM open source conçu dès le départ pour des agents IA plutôt qu’un CRM classique auquel on ajoute un chatbot.

Pourquoi regarder

Bon exemple d’application métier “agentic-first”, utile pour comprendre comment repenser les workflows autour d’agents.

Cas d’usage

Prospection, enrichissement, suivi, work queue et automatisation d’actions commerciales.

À étudier autant pour son architecture produit que pour son code.
GitHub trycompai/crm
08 AI Security

NVIDIA SkillSpector

Skills · Prompt injection · Supply chain

Ce que c’est

Un scanner de sécurité pour skills d’agents IA : prompt injection, exfiltration, patterns malveillants et risques supply-chain.

Pourquoi regarder

Les skills et outils d’agents héritent souvent de privilèges importants. Ce projet fournit une couche de contrôle avant installation.

Cas d’usage

Gate de sécurité avant installation de skills Claude Code, Codex, MCP et autres extensions agentiques.

Très pertinent pour mettre en place une politique d’approbation des extensions d’agents.
GitHub NVIDIA/SkillSpector

29 Spec-Driven Development

SandyKit

Spec · Plan · Tasks · Tests

Ce que c’est

Un CLI open source qui structure le développement assisté par IA en imposant un pipeline : spécification, plan, tâches, code, tests et revue.

Pourquoi regarder

Il répond directement au problème du “vibe coding” : du code rapide mais peu traçable, mal documenté et difficile à maintenir.

Cas d’usage

Transformer un brief en développement structuré, conserver les artefacts du projet et encadrer le travail d’un agent de code.

Particulièrement intéressant pour les équipes qui veulent rendre le développement IA audit-able et reproductible.
GitHub kuatejoelparfait-Data/Sandykit-v2
30 Agent Orchestration

Méthode KUATE

K·U·A·T·E · Memory · Multi-agent

Ce que c’est

Une méthode d’orchestration d’agents IA structurée autour de rôles spécialisés, phases explicites, mémoire persistante et continuité du contexte.

Pourquoi regarder

Elle cherche à transformer l’agent ponctuel en système de travail structuré : moins d’improvisation, plus de contrôle et de continuité.

Cas d’usage

Organisation de workflows multi-agents, développement logiciel assisté, recherche et tâches complexes en plusieurs phases.

Complément naturel de SandyKit : SandyKit structure le cycle logiciel, KUATE structure l’orchestration des agents.
GitHub kuatejoelparfait-Data/methode-kuate
