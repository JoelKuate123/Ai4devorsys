Tests — MiniCRM

Les tests tournent directement dans le navigateur. Aucune installation, aucun terminal. Ce sont exactement les mêmes fichiers que ceux qu'exécute node run-tests.js.

À quoi servent ces tests ? À vous dire, en deux secondes, si une modification — la vôtre ou celle d'un assistant IA — a cassé quelque chose. C'est le seul garde-fou fiable quand on laisse une IA écrire du code.
