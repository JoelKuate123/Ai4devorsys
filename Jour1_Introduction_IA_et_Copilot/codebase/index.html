Ce qu'il y a dans le dossier, et pourquoi il n'y a pas de JavaScript aujourd'hui.

Dans quel ordre travailler

  1. Ouvrez exercice_1_assistant_regles/index.html et cliquez sur les neuf questions.
  2. Regardez les quatre questions qu'il ne comprend pas : chacune demanderait une règle de plus, écrite à la main.
  3. Ouvrez assistant.css dans VS Code et trouvez les deux lignes qui font tout le travail (section 4 du fichier).
  4. Ajoutez une dixième règle : un lien, un bloc, et c'est fini.
  5. Passez à l'exercice 2 : le prompt, la page produite, la grille sur 7.
Pas de JavaScript aujourd'hui. Vous allez lire et écrire du HTML et du CSS, et faire produire le reste par l'assistant. C'est délibéré : on apprend d'abord à relire ce qu'une IA écrit, avant d'apprendre à écrire soi-même.
Un conseil pour la journée : installez l'extension Live Preview de Microsoft dans VS Code. Clic droit sur un fichier HTML, Show Preview, et la page se recharge toute seule à chaque enregistrement.
