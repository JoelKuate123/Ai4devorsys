Exercice pratique · 15 à 20 minutes

Convertir et quantifier un modèle avec GGUF My Repo

Objectif : prendre un petit modèle Hugging Face, le convertir en GGUF, appliquer une quantification Q4_K_M, puis expliquer ce qui a réellement changé.

Modèle proposé : Qwen/Qwen2.5-0.5B-Instruct
0.5B = environ 0,5 milliard de paramètres. « Instruct » = variante adaptée au suivi d’instructions.

Ouvrir GGUF My Repo   Voir le modèle source
Attention au vocabulaire : dans cet exercice, vous ne changez pas les connaissances du modèle. Vous changez surtout son format de stockage et la précision de ses poids grâce à la quantification.

Consigne

1
Connectez-vous à Hugging Face et ouvrez le Space.

Le Space exige une connexion Hugging Face pour créer le nouveau dépôt sous votre compte.

2
Dans « Hub Model ID », recherchez :

Qwen/Qwen2.5-0.5B-Instruct

3
Choisissez la méthode de quantification Q4_K_M.

Q = Quantization ; 4 = famille proche de 4 bits ; K = famille de quantification par blocs ; M = variante Medium.

4
Laissez « Use Imatrix Quantization » désactivé pour ce premier exercice.

Une importance matrix (imatrix) utilise des données représentatives pour guider la quantification et préserver davantage les parties importantes du modèle. Nous l’écartons ici pour garder le TP simple.

5
Laissez « Split Model » désactivé.

« Split » signifie découper un gros GGUF en plusieurs fichiers. Avec un modèle de 0,5B paramètres, ce n’est pas nécessaire pour cet exercice.

6
Lancez la conversion.

Le Space convertit le dépôt Hugging Face vers GGUF, quantifie les poids selon la méthode choisie, puis crée un nouveau dépôt contenant votre GGUF.

Questions de compréhension

Bonus — comparer deux quantifications

Recommencez avec Q8_0. Comparez ensuite la taille de Q8_0 et de Q4_K_M.
Résultat attendu : vous devez être capable d’expliquer que la conversion GGUF prépare le modèle pour des runtimes compatibles comme llama.cpp, tandis que la quantification réduit la précision numérique des poids afin de diminuer la taille et la mémoire nécessaire, avec un risque de perte de qualité.
Sources : documentation officielle llama.cpp / GGUF My Repo et fiche du modèle Qwen2.5-0.5B-Instruct. Le Space propose actuellement notamment Q2_K, Q3_K, Q4_K_M, Q5_K_M, Q6_K et Q8_0.
