Journée 3 · Exercices guidés

Les LLM · RAG local · MCP. Trois exercices, quinze étapes. La seule journée qui demande Python — et on explique pourquoi.

Durée totale 3 h 30 Niveau débutant Code base Python + interface web Tests pytest
Chaque étape tient en une action. Faites-les dans l'ordre, et ne passez à la suivante que lorsque la précédente fonctionne. Les cases se cochent à l'écran, et la page retient vos coches. Les zones de texte sont à remplir : c'est là que se joue l'apprentissage.
Aujourd'hui, on installe Python. C'est la seule journée qui le demande, et il y a trois raisons précises à cela : un RAG lit des fichiers sur le disque, un serveur MCP parle par l'entrée standard d'un processus, et l'écosystème de l'IA est en Python. L'interface web, elle, reste en HTML/CSS/JS.

Avant de commencer · 15 minutes

0Installer Python et l'environnement
Debutant

Suivez les commandes dans l'ordre. Chacune doit se terminer sans message rouge avant de passer à la suivante.

# 1. Vérifier Python (il faut 3.10 ou plus récent)
python --version

# 2. Se placer dans la code base du jour 3
cd Jour3_LLM_et_RAG_local/codebase

# 3. Créer l'environnement virtuel (un dossier .venv apparaît)
python -m venv .venv

# 4. L'activer — WINDOWS
.venv\Scripts\activate

# 4bis. L'activer — macOS / Linux
source .venv/bin/activate

# 5. Installer les bibliothèques
pip install -r requirements.txt

# 6. Copier la configuration
copy .env.example .env        # Windows
cp .env.example .env          # macOS / Linux

# 7. Vérifier que tout marche
pytest -q
Sous Windows, l'étape 4 échoue souvent avec un message sur la politique d'exécution. La commande à lancer une fois, dans PowerShell : Set-ExecutionPolicy -Scope CurrentUser RemoteSigned. Signalez-le au formateur plutôt que de perdre dix minutes.

Exercice 6 · Un « ChatGPT » local sur vos documents

Durée : 1 h 15 · En binôme · Dossier exercice_6_rag_local/

6.1Faire tourner le RAG en terminal
Debutant
python exercice_6_rag_local/rag.py

Posez les questions suivantes, dans l'ordre :

  1. « Combien de jours de congé annuel ? »
  2. « Quel est le plafond de remboursement d'un repas ? »
  3. « Quelle est la capitale de l'Australie ? »

La troisième question : qu'a-t-il répondu ?

Intermediaire

Exercice 7 · MCP, brancher un assistant sur votre base

Durée : 1 heure · En binôme · Dossier exercice_7_mcp/

7.1Voir le protocole passer
Debutant
python exercice_7_mcp/serveur_mcp.py --demo

Cinq messages défilent. Notez ce que fait chacun.

MessageÀ quoi il sert
initialize
notifications/initialized
tools/list
tools/call

Lequel des cinq ne reçoit AUCUNE réponse, et pourquoi ?

7.2Voir les deux côtés du tuyau
Debutant
python exercice_7_mcp/client_mcp_minimal.py

Ce script démarre le serveur comme un processus enfant et lui parle. C'est exactement ce que fait Claude Code, Codex ou Copilot CLI.

MCP vous paraît-il plus simple ou plus compliqué qu'avant cet exercice ?

7.3Dégradez une description, et observez
Intermediaire

C'est l'expérience la plus instructive du module.

  1. Dans serveur_mcp.py, trouvez la description de rechercher_documents.
  2. Remplacez-la temporairement par : "Cherche des trucs."
  3. Relancez --demo, puis branchez le serveur sur votre assistant.
  4. Posez une question sur les congés.

L'assistant a-t-il appelé l'outil ? Avec quels arguments ?

Remettez la vraie description ensuite. Ce que vous venez d'observer, c'est que la qualité d'un serveur MCP se joue à 80 % dans les descriptions, pas dans le code.
7.4Ajoutez un quatrième outil
Intermediaire

Un outil compter_les_mots qui renvoie le nombre de mots d'un document donné. Trois endroits à modifier :

  1. La liste OUTILS : nom, description, schéma des arguments.
  2. Une fonction outil_compter_les_mots(arguments).
  3. Le dictionnaire IMPLEMENTATIONS.
pytest exercice_7_mcp/ -v
7.5Branchez-le sur un vrai assistant
Avance

Ouvrez exercice_7_mcp/configuration_mcp.md et suivez la section correspondant à votre outil.

# Claude Code
claude mcp add rag-local -- python exercice_7_mcp/serveur_mcp.py

# Codex : ajouter dans ~/.codex/config.toml
[mcp_servers.rag_local]
command = "python"
args = ["exercice_7_mcp/serveur_mcp.py"]

# Copilot CLI
/mcp add

Posez-lui une question sur vos congés. A-t-il cité le fichier source ?
